# ADR-0005：项目优先的工作流编辑器

- 状态：Accepted
- 日期：2026-07-30

## 背景

早期工作流页面把“选择模板”当作每次进入页面的入口，容易让用户误以为模板就是工作流本身。
节点库同时暴露过多内部步骤，创建、排序、连线和解释也不完整。另一个本地材料工作流服务
CatGo 默认使用 `127.0.0.1:8000`；当两个服务或浏览器标签共用这个地址时，CatGo 前端会向
CatEx 后端请求其专属接口，产生重复的 404 日志。

## 调研结论

CatGo 的工作流实现值得借鉴的不是节点数量，而是以下交互原则：

- 画布是工作流的权威视图，模板只是可选起点；
- 节点按用途渐进展示，属性与说明固定出现在侧栏；
- 支持选择、删除、重连、自动布局和键盘操作；
- 工作区状态必须在页面切换后保持；
- 项目、工作流草稿、发布版本和运行记录是不同层次。

CatEx 不复制 CatGo 的大型通用节点目录。当前产品范围仍限定为周期性催化、VASP 与 Slurm，
因此新建节点面板只暴露输入准备、可选 CHGNet、五类 VASP 计算和结果收集八种科学节点。
旧草稿中的历史节点仍可读取，但不继续增加新用户的认知负担。

## 决策

1. 用户必须先创建或选择项目，工作流明确隶属于该项目；
2. 项目页和工作流页同时显示真实的本地保存目录；
3. 新项目进入工作流时允许直接创建空白画布，也可选择模板；
4. 选定模板后进入实际画布，离开页面再返回时不重新显示模板选择；
5. 空白处右键可搜索并创建节点；节点右键可插入后续节点、复制、删除或打开对应工作台；
6. 新节点默认放在当前节点之后并尝试建立第一个类型兼容的连接，随后执行拓扑自动布局；
7. 连线可以选择、删除、重连和自由连接，但禁止类型不兼容的连接与有向环；
8. 右侧说明栏提供作用、使用时机、开始前需要什么、产出及科学注意事项；
9. 草稿保存在项目后端存储中；发布版本和运行图继续遵循 ADR-0004 的不可变规则；
10. CatEx 一体化启动器默认监听 `127.0.0.1:8765`，与常见的 CatGo `8000` 服务隔离。

## 后果

- 模板不再阻挡已有工作流，也不会在页面切换后覆盖草稿；
- 空白建图和小型 VASP 科研流程更直接；
- 自动布局只改变视觉位置，不改变依赖关系或科学参数；
- 自动连接只在端口类型唯一兼容且不会产生环时执行，用户仍可手工调整；
- CatGo 和 CatEx 可以同时运行，但用户仍应关闭指向旧端口的过期浏览器标签；
- 未来新增节点必须先证明属于当前科学范围，并补齐双语说明、端口定义和测试。
