# Workflow Studio 与 Campaign

## 三种工作方式

“工作流”页面包含：

- **快速构建**：选择结构优化、优化+静态、频率、DOS、MD 或 CHGNet+VASP 模板；
- **节点图**：从节点库添加节点，拖动、连接、复制、删除并编辑节点参数；
- **发布与运行**：保存草稿、发布不可变版本、创建运行快照。

只有项目草稿可修改。发布版本按内容哈希标识；运行快照复制发布版本，后续草稿变化不会影响它。
“创建运行快照”只生成阶段计划，不建立 SSH 连接、不写远端目录、不执行 VASP 或 `sbatch`。

## 多阶段 VASP 计划

阶段编译器目前识别：

- CHGNet 本地预弛豫；
- VASP 结构优化；
- VASP 静态计算；
- VASP 振动频率；
- VASP DOS；
- VASP 从头算 MD。

每个阶段保存依赖、执行后端、目录名、结构来源、INCAR 覆盖、必需输入和预期输出。科学参数不会
因失败而自动改变；续算需要新的人工动作和运行记录。

## Campaign

Campaign 用于长期筛选和设计，不要求用户一直面对一张不断变大的 DAG。一个 Campaign 可以：

- 固定一个工作流发布版本；
- 登记候选名称、结构 Artifact 和任意 JSON 设计变量；
- 追加 advance、hold、exclude、repeat 等科研决策及其依据；
- 保留候选数量和决策数量。

当前 Campaign 不自动生成结构、不批量提交作业，也不自动根据数值淘汰候选。这些能力必须在
配额策略、失败域和人工门禁完成后再接入。
