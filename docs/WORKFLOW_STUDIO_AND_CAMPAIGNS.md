# Workflow Studio 与 Campaign

## 项目、保存位置与进入方式

工作流必须属于一个 CatEx 项目。首次启动先进入“项目”页；创建或选择项目后再进入“工作流”。
项目页显示数据根目录，工作流标题下显示当前项目的精确目录：

```text
<CATEX_WORKBENCH_DATA_ROOT>/projects/<project-id>
```

结构 Artifact、计算配置、工作流草稿、发布版本和运行记录都位于这个项目范围中。浏览器刷新或切换
到其他页面不会把已经选择的模板重新弹出来，也不会用默认模板覆盖当前草稿。

如果项目还没有工作流，可以：

- 直接新建空白画布；
- 选择一个 VASP 或 CHGNet+VASP 模板作为起点。

模板只是一次性的起点，不是后续编辑模式，也不是必选步骤。

## 画布交互

- 在空白画布上右键，可搜索并创建新节点；
- 选择节点后从左侧添加，新节点会放在它的后面，并在端口兼容时自动连接；
- 节点右键可插入后续节点、复制、删除或打开相应的科学工作台；
- 拖动端口可自由连接，拖动已有连线端点可以重连；
- 选择连线后按 `Delete` 或 `Backspace` 可删除，也可以右键删除；
- “自动布局”按依赖关系重新排列节点，只改变位置，不改变科学参数或依赖；
- 类型不兼容或会产生有向环的连接会被拒绝；
- 右侧栏按“说明 / 参数 / 输入输出”展示节点用途、前置条件、产出和科学注意事项。

新建面板只显示当前 VASP 催化范围中的八类节点：VASP 输入准备、CHGNet 预弛豫、优化、静态、
频率、DOS、MD 和结果收集。旧草稿里的历史节点仍能打开，但不会继续塞进新用户的节点面板。

## 草稿、发布与运行

只有项目草稿可修改。点击“保存草稿”后，画布写入当前项目；发布版本按内容哈希标识，发布后不可
修改。运行快照复制发布版本，后续草稿变化不会影响它。

“版本与运行”用于查看历史版本、发布当前草稿并创建运行快照。“创建运行快照”只生成阶段计划，
不建立 SSH 连接、不写远端目录、不执行 VASP 或 `sbatch`。实际上传、远端目录创建和作业提交仍在
“运行中心”经过独立确认。

## 多阶段 VASP 计划

阶段编译器目前识别：

- CHGNet 本地预弛豫；
- VASP 结构优化；
- VASP 静态计算；
- VASP 振动频率；
- VASP DOS；
- VASP 从头算 MD。

每个阶段保存依赖、执行后端、目录名、结构来源、INCAR 覆盖、必需输入和预期输出。科学参数不会
因失败而自动改变；续算需要新的人工动作和运行记录。

## Campaign

Campaign 用于长期筛选和设计，不要求用户一直面对一张不断变大的 DAG。一个 Campaign 可以：

- 固定一个工作流发布版本；
- 登记候选名称、结构 Artifact 和任意 JSON 设计变量；
- 追加 advance、hold、exclude、repeat 等科研决策及其依据；
- 保留候选数量和决策数量。

当前 Campaign 不自动生成结构、不批量提交作业，也不自动根据数值淘汰候选。这些能力必须在
配额策略、失败域和人工门禁完成后再接入。
